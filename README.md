# India Volunteer Opportunity Research Dashboard 📊

## 📌 Introduction

India Volunteer Opportunity Research Dashboard is an excel-based research and analysis project involving collection of data and other relevant information on the volunteer opportunities, internships, fellowships, and social initiatives available to students in India.

The project was completed through the organization of information in a presentable manner and visualized using dashboard graphs and other excel tools to highlight key aspects of the information discovered during the research process.

## 🎯 Purpose

The purpose of this project is to collate and organize the information relevant to opportunities available to students in India.

The collected information was organized to identify trends and highlight notable aspects of each of the social initiatives, internships, fellowships, and volunteer opportunities collated for this report.

## 📊 Description

India volunteer opportunity research dashboard is a spreadsheet-based project that involves extensive data collection and collation to organize and present key aspects of the various opportunities available to students in India.

The project highlights the following:

Well-organized data relevant to volunteer opportunities in India.

Organization and presentation of information on the various opportunities and their requirements.

Use of visual elements to represent data and key aspects identified during the research process.

Interactivity of the dashboard to enhance analysis and ease of use where possible using excel tools.

A dashboard summary of the project highlighting the most important aspects of the research.

The project file is titled: India_Volunteer_Opportunity_Research_Dashboard.xlsx
